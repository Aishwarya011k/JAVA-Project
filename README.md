# Disaster Resource Relocation System

## 📌 Project Overview

The **Disaster Resource Relocation System** is a Java-based console application designed to simulate the allocation and relocation of essential resources during disaster situations.  
It helps manage and distribute resources such as food, medical supplies, and rescue units efficiently to affected areas.

---

## 🛠️ Features

- Resource management using Object-Oriented Programming
- Supports multiple resource types:
  - Food Resources
  - Medical Resources
  - Rescue Resources
- Simple and clear Java console execution
- Modular and extensible code structure
